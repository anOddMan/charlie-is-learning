📋 项目概述

ECC 是一个完整的 Claude Code 配置系统，不止是配置文件，而是包含技能体系、本能行为、记忆优化、持续学习、安全扫描和研究优先开发模式的整套系统。

⚠️ 重要定位

这是一个 Claude Code 插件，可直接安装或手动复制组件。支持 Claude Code、Codex、Cursor、OpenCode、Gemini 及其他 AI 智能体框架。

核心价值

  • 10+ 个月高强度日常使用与真实产品开发迭代打磨
  • 生产环境就绪的智能体、技能模块、钩子、规则、MCP 配置
  • 兼容传统命令的适配层
  • 跨平台支持 Windows、macOS、Linux

🔧 安装方式

插件安装(推荐)
手动安装
规则安装

方式1：插件安装（最便捷）

# 添加市场 /plugin marketplace add https://github.com/affaan-m/everything-claude-code # 安装插件 /plugin install ecc@ecc # 查看可用命令 /plugin list ecc@ecc
⚠️ 注意事项

1. Claude Code 插件无法自动分发 rules，需手动复制

2. 已通过插件安装后，不要再运行完整安装脚本，避免重复

3. multi-* 命令需额外安装 ccg-workflow 运行时

方式2：手动安装

# 克隆仓库 git clone https://github.com/affaan-m/everything-claude-code.git # 复制智能体 cp everything-claude-code/agents/*.md ~/.claude/agents/ # 复制规则 mkdir -p ~/.claude/rules cp -r everything-claude-code/rules/common ~/.claude/rules/ cp -r everything-claude-code/rules/typescript ~/.claude/rules/ # 复制技能 cp -r everything-claude-code/.agents/skills/* ~/.claude/skills/ # 复制命令 mkdir -p ~/.claude/commands cp everything-claude-code/commands/*.md ~/.claude/commands/

规则安装（插件用户必做）

# 用户级规则（对所有项目生效） mkdir -p ~/.claude/rules cp -r rules/common ~/.claude/rules/ cp -r rules/typescript ~/.claude/rules/ # 选择技术栈 # 项目级规则（仅当前项目） mkdir -p .claude/rules cp -r rules/common .claude/rules/

💡 关键概念

概念定义示例
代理 (Agent) 以有限范围处理委托任务的子智能体 code-reviewer, architect, tdd-guide
技能 (Skill) 由命令或代理调用的工作流定义 tdd-workflow, security-review
钩子 (Hook) 在工具事件时触发的自动化逻辑 PreToolUse, PostToolUse, Stop
规则 (Rule) 始终遵循的指南，分通用+语言特定 common/testing.md, typescript/*.md
上下文 (Context) 动态注入的系统提示 dev.md, review.md, research.md

⚙️ 配置要点

⚠️ 上下文窗口管理（关键！）

不要一次启用所有 MCP。经验法则：

  • 配置 20-30 个 MCP
  • 每个项目保持启用少于 10 个
  • 活动工具少于 80 个
  • 使用 disabledMcpServers 禁用未使用的

包管理器检测

自动检测优先级：环境变量 → 项目配置 → package.json → 锁文件 → 全局配置

export CLAUDE_PACKAGE_MANAGER=pnpm node scripts/setup-package-manager.js --global pnpm node scripts/setup-package-manager.js --detect /setup-pm # Claude Code 内命令

钩子运行时控制

export ECC_HOOK_PROFILE=standard # 严格度配置 export ECC_DISABLED_HOOKS="pre:bash:tmux-reminder,post:edit:typecheck"

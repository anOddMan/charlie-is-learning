三、Chatbot Arena (LMSYS)

3.1 体系简介

Chatbot Arena（现称 LMArena）由 LMSYS Org（UC Berkeley / UCSD / CMU）于 2023 年 5 月推出，是当前最受认可的 人类偏好盲评排行榜。截至 2025 年已收集 300 万+ 对比较、1100 万+ 投票，评测 400+ 模型。 用户提交任意 prompt，同时看到两个匿名模型的回复进行投票，平台通过 Bradley-Terry 模型拟合 Elo 分数。

核心优势：人类直接评判，难以作弊，与真实用户体验高度一致。是目前"含金量"最高的 LLM 排行榜。

3.2 核心方法

要素说明
评测方式匿名盲评 — 用户同时看到 A/B 两个模型的回复，投票选出更好的
统计模型Bradley-Terry 模型通过 MLE 估计潜在"强度"参数，映射到 Elo 量表（×173.7）
K-factorK=4（远低于国际象棋的 K=20），降低单日噪声
置信区间95% CI，少票数模型区间更宽（约 ±40 分）
专项赛道Agent Arena、Search Arena、RepoChat 等垂直领域

3.3 使用方法

URL 访问地址

https://lmarena.ai

# 查看排行榜
https://lmarena.ai/?leaderboard

四、MMLU / MMLU-Pro

4.1 体系简介

MMLU（Massive Multitask Language Understanding） 由 UC Berkeley 推出，覆盖 57 个学科（人文、社科、STEM、其他）， ~14,000 道选择题，是使用最广泛的知识型 LLM 基准。到 2025 年，原始 MMLU 已近饱和（前沿模型超 90%）， 因此推出了 MMLU-Pro：答案选项从 4 个扩展到 10 个，增加推理强度，减少 prompt 敏感性。

4.2 核心方法

维度MMLUMMLU-Pro
学科数5714 大类
题目量~14,00012,000+
选项数4 个10 个
推理要求中低高（需 CoT 推理）
Prompt 敏感性4-5%~2%
前沿模型得分90%+（近饱和）60-75%（仍有区分度）

4.3 使用方法

BASH 通过 LM Evaluation Harness 运行 
# 安装 lm-eval
pip install lm-eval

# 评测 MMLU（57 科全部）
lm_eval --model hf \
    --model_args pretrained=mistralai/Mistral-7B-v0.1 \
    --tasks mmlu \
    --num_fewshot 5 \
    --batch_size auto \
    --device cuda:0

# 评测 MMLU-Pro（需加载对应 task）
lm_eval --model hf \
    --model_args pretrained=model-name \
    --tasks mmlu_pro \
    --num_fewshot 5 \
    --apply_chat_template

五、HumanEval / MBPP

5.1 体系简介

HumanEval 由 OpenAI 推出，包含 164 道手写编程题，使用 Pass@k 指标 （生成 k 个候选答案中至少有一个通过单元测试的概率）。配合 MBPP（1,000 道众包 Python 题）构成代码生成的标准评测组合。

5.2 核心指标

Pass@k 计算公式：

MATHPass@k 定义
# Pass@k: 从 n 个样本中生成 k 个，至少有一个通过测试的概率
pass_at_k(n, c, k) = 1 - C(n-c, k) / C(n, k)

# 其中：n = 每个问题的总样本数，c = 正确的样本数，k = 选取数
# 典型取值：n=200, k=1 → Pass@1（首次生成即正确的概率）

5.3 使用方法

BASH HumanEval 评测 
# 克隆仓库
git clone https://github.com/openai/human-eval
cd human-eval
pip install -e .

# 生成代码样本（以你的模型生成）
python generate_samples.py --model your-model --output samples.jsonl

# 评估 Pass@k
evaluate_functional_correctness samples.jsonl
BASH 通过 LM Eval Harness 运行 
# 一键评测 HumanEval + MBPP
lm_eval --model hf \
    --model_args pretrained=codellama/CodeLlama-7b-hf \
    --tasks humaneval,mbpp \
    --batch_size auto

5.4 案例：代码模型选型

中等代码模型（DeepSeek-Coder-33B）~79%日常开发辅助
前沿模型（GPT-4o / Claude 4）~92%复杂算法、架构设计

六、LM Evaluation Harness

6.1 体系简介

LM Evaluation Harness 由 EleutherAI 开发，是当前最广泛使用的 统一评测框架，支持 200+ 基准任务。HuggingFace Open LLM Leaderboard、 NVIDIA、Cohere、BigScience 等均基于此框架。

定位：它不是一个"基准"，而是一个评测执行引擎——你可以在同一个框架下一键运行 MMLU、HellaSwag、GSM8K、HumanEval 等数十个基准。

6.2 安装

BASH安装 LM Eval Harness
# 基础安装
pip install lm-eval

# 安装 HuggingFace 后端（必须！）
pip install "lm_eval[hf]"

# 安装 vLLM 后端（加速推理）
pip install "lm_eval[vllm]"

# 安装 API 后端（评测 OpenAI / Anthropic 等）
pip install "lm_eval[api]"

6.3 核心命令

BASH常用评测命令
# 列出所有可用任务
lm-eval ls tasks

# 基础评测（HuggingFace 模型）
lm-eval run --model hf \
    --model_args pretrained=meta-llama/Llama-2-7b-hf \
    --tasks hellaswag,arc_challenge,winogrande \
    --device cuda:0 \
    --batch_size auto

# 运行 Open LLM Leaderboard 标准套件
lm-eval --model hf \
    --model_args pretrained=your-model \
    --tasks leaderboard

# 评测 Chat 模型（使用对话模板）
lm-eval --model hf \
    --model_args pretrained=mistralai/Mistral-7B-Instruct-v0.2 \
    --tasks mmlu \
    --num_fewshot 5 \
    --apply_chat_template \
    --fewshot_as_multiturn

# 使用 vLLM 后端（速度更快）
lm-eval --model vllm \
    --model_args pretrained=model-name \
    --tasks gsm8k \
    --batch_size auto

# 保存结果到文件
lm-eval --model hf \
    --model_args pretrained=model-name \
    --tasks mmlu \
    --output_path ./results \
    --log_samples

6.4 自定义评测任务

通过 YAML 配置文件创建自定义任务：

YAMLmy_custom_task.yaml
task: my_custom_task
dataset_path: json
dataset_kwargs:
  data_files: ./my_data/val.jsonl
output_type: multiple_choice
num_fewshot: 3

doc_to_text: "{{question}}\nA. {{A}}\nB. {{B}}\nC. {{C}}\nD. {{D}}\n答案:"
doc_to_choice: ["A", "B", "C", "D"]
doc_to_target: "{{answer}}"

metric_list:
  - metric: acc
    aggregation: mean
  - metric: acc_norm
    aggregation: mean

metadata:
  version: 1.0
最佳实践：评测 Chat/Instruct 模型时记得加 --apply_chat_template，否则会因格式不匹配导致分数严重偏低。评测推理模型（如 DeepSeek-R1）时建议配合 --fewshot_as_multiturn。

七、AlpacaEval 2.0

7.1 体系简介

AlpacaEval 由 Stanford tatsu-lab 开发，通过 LLM-as-Judge 方式实现 快速自动评测（<3 分钟、$3.50/次）。2.0 版本引入长度控制（Length-Controlled）Win Rate， 与 Chatbot Arena 的 Spearman 相关性高达 0.98。

7.2 核心方法

要素AlpacaEval 1.0AlpacaEval 2.0
评判模型GPT-4GPT-4 Turbo（更快更便宜）
基线模型text-davinci-003GPT-4 Turbo
长度偏差严重（偏好长回复）已控制（GLM 回归去偏）
Arena 相关性0.930.98
评测成本~$7~$3.50

7.3 使用方法

BASHAlpacaEval 命令行评测
# 安装
pip install alpaca-eval

# 准备模型输出文件 (JSON)
# 格式：[{"instruction": "...", "output": "..."}, ...]

# 运行评测
export OPENAI_API_KEY=your_key
alpaca_eval --model_outputs './my_model_outputs.json'

# 从 HuggingFace 模型直接评测
alpaca_eval evaluate_from_model \
    --model_path meta-llama/Llama-2-7b-chat-hf \
    --output_path ./results
PYTHONPython API 评测
from alpaca_eval import evaluate
import pandas as pd

# 准备评测数据
df = pd.DataFrame([
    {"instruction": "什么是机器学习？",
     "output": "机器学习是..."},
])

# 执行评测
leaderboard, annotations = evaluate(
    model_outputs=df,
    annotators_config="weighted_alpaca_eval_gpt4_turbo",
    output_path="./results",
    is_return_instead_of_print=True,
)

# 查看结果
print(leaderboard.loc["MyModel"])

八、SuperCLUE（中文综合评测标杆）

8.1 体系简介

SuperCLUE 是 CLUE 基准的延续，专为中文大模型设计。核心特色： 所有题目均为原创新题，约 2 个月 100% 替换，杜绝过拟合。 每期 ~1200-1600 道多轮简答题，覆盖六大维度。

官网：cluebenchmarks.com/superclue.html

8.2 六大评测维度（2025）

维度评测内容评价方式
数学推理几何、代数、概率统计（竞赛级别）人工校验答案 → 0/1 得分
科学推理物理、化学、生物（研究生级别）人工校验答案 → 0/1 得分
代码生成数据结构、算法、Web 应用（HumanEval 中文升级版）单元测试通过 → 0/1 得分
智能体 Agent10+ 场景工具调用（汽车控制、股票交易、智能家居等）任务完成状态比对
精确指令遵循格式约束、结构约束、量化约束规则脚本评估
文本理解与创作摘要、阅读理解、指代消解、长文本人工校验 + 多维评价

8.4 案例：汽车之家仓颉大模型

SuperCLUE 发布 SuperCLUE-AutoQA 汽车知识测评基准，覆盖 5 大维度（汽车咨询、对比、推荐、资讯、用车）11 个子维度。 汽车之家自研"仓颉大模型"以 72.96 分位列第一，体现出三个能力：

  • 懂用户，善理解：对多条件复杂提问（"家里有两个小孩，预算20万左右，想要空间大的SUV"）答案准确

  • 不编造，给解法：不存在有效答案时明确告知并提供替代方案

十、OpenCompass（司南）

10.1 体系简介

OpenCompass 由上海人工智能实验室主导，联合复旦大学、商汤科技等机构开发。 提供 70+ 评测数据集、50+ 模型支持，是国产模型评测的事实标准平台。

GitHub：open-compass/opencompass · 文档：opencompass.readthedocs.io

10.2 安装与配置

BASH安装 OpenCompass
# 创建环境
conda create --name opencompass python=3.10 -y
conda activate opencompass

# 安装
git clone https://github.com/open-compass/opencompass.git
cd opencompass
pip install -e .
pip install -r requirements.txt

10.3 评测模式对比

模式方法适用示例
ppl（困惑度）问题+候选答案拼接，计算困惑度，选最低的Base 模型、选择题C-Eval、MMLU
gen（生成）模型直接生成答案，规则/LLM 后处理提取Chat 模型、开放问答GSM8K、HumanEval
clp（条件对数概率）计算下一个 token 对数概率高效选择题ARC、HellaSwag

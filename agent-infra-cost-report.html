2.3 成本估算模型

2.3.1 Agent 月度总成本公式

MATHAgent 月度 TCO 计算公式
月总成本 = LLM推理成本 + Embedding成本 + 基础设施成本 + 人力运维成本 + 第三方服务成本

# 1. LLM 推理成本
LLM推理成本 = 月请求数 × 每请求平均Token × (输入占比 × 输入单价 + 输出占比 × 输出单价)
            × (1 - 缓存命中率 × 缓存折扣)

# 2. Embedding 成本（RAG 场景）
Embedding成本 = (文档块数 × 块Token数 × Embedding单价)  # 离线索引
              + (月查询数 × 查询Token数 × Embedding单价)  # 在线查询

# 3. 基础设施成本
基础设施 = GPU实例成本(实例数 × 小时单价 × 月运行小时)
         + 存储成本(向量库 + 关系库 + 对象存储 + 日志)
         + 网络成本(跨AZ流量 + 公网出向)

# 4. 人力运维成本
人力成本 = (DevOps人力 + ML工程人力) × 月工资 × Agent项目时间占比

# 5. 第三方服务
第三方成本 = 监控工具($200-2000/月) + API管理 (LiteLLM/网关) + 安全审计

场景月请求量推荐模型路由月 LLM 成本月基础设施月总成本

4.1 五步决策法

步骤核心问题输出物关键参数
Step 1：定义场景 Agent 做什么？是内部工具还是面向客户？ 场景描述 + SLA 要求 并发用户数、延迟要求（<500ms / <2s / <10s）、可用性（99% / 99.9% / 99.99%）
Step 2：估算规模 每天多少请求？每次消耗多少 Token？ 容量规划表 日请求量、平均 Token/请求、峰值倍数、数据量（文档数 × 块数）
Step 3：设计架构 用什么模型？自建还是 API？什么数据库？ 架构图 + 技术选型文档 模型列表、GPU 选型、存储方案、编排框架
Step 4：成本测算 LLM、基础设施、人力各多少钱？ TCO 模型 + ROI 分析 月 Token 量 × 单价 + 基础设施月费 + 人力成本
Step 5：做决策 Build vs Buy？云端 vs 自建？ 决策报告 TCO 对比、ROI 周期、风险清单

## 二、模型路由策略（输入占比%）
入门模型 (Haiku/Flash)   = 60%         # 简单问答、检索、分类

推理模型 (DeepSeek-R1)     = 2%          # 数学/逻辑复杂题

推理输入/输出  = 0.55 / 2.19

如何使用此模型：
1. 替换「业务参数」中的数值为你实际的 MAU、日请求数、Token 量
2. 根据你的模型选择调整「路由策略」和「定价参数」
3. 对比不同路由策略下的成本差异——调整入门/标准/高级占比看变化
4. 单次请求成本 <$0.01 是健康状态，>$0.05 需要优化

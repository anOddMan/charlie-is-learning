战略决策框架：三步定位法

1.1 企业 AI 成熟度自评

在立项前，企业必须客观评估自身基础能力。请根据以下五个维度进行自评：

评估维度Level 1（起步）Level 2（发展）Level 3（成熟）
数据基础数据分散、未治理有基础数据仓库/数据湖数据中台完善、质量高
技术团队无 AI 团队有基础开发团队有 ML/NLP 专业人才
IT 基础设施传统 IT已上云有 GPU 算力资源
业务数字化纸质/线下为主核心系统已数字化全面数字化 + API 化
AI 预算（年）<50 万50-500 万>500 万
🚨 核心原则：Level 1 的企业绝对不要自己训练大模型；Level 3 的企业也未必需要训练大模型。

应用场景选择与优先级排序

4.1 通用场景评估矩阵

对每个候选场景从 4 个维度打分（1-5 分）：

评估维度权重评判标准
业务价值（V）30%降本金额 / 增收金额 / 效率提升倍数
实施难度（D）25%技术复杂度 / 系统集成难度 / 数据准备量（越高越简单）
风险容忍度（R）25%出错后果是否可控 / 是否有"人在环路"兜底
数据就绪度（A）20%业务数据是否已有 / 质量 / API 可获取性
优先级得分 = V × 0.3 + D × 0.25 + R × 0.25 + A × 0.2

销售估算五步法

🎯 核心原则总结

八字方针：小步快跑，价值驱动
"小步试错，快速迭代。不为概念买单，只为业务结果付费。"
1
先用再建

首选成熟 API 和 SaaS 方案快速跑通闭环，绝不一开始就大笔采购算力显卡。

2
场景导向

必须从具体业务痛点出发，紧盯降本增效，不为 AI 技术标签而强蹭 AI。

3
最小可行

每阶段最小成本原则，只为当前目标买单。不追求过早架构完美。

4
人机协作

Agent 定位是"辅助人类副驾驶"，重要节点一律保留人工审批兜底。

5
快速迭代

以 2-4 周为滚动迭代周期，根据核心用户真实数据快速调整优化方向。

6
度量驱动

拒绝感性描述，对准确率、延迟、API 开销、人力效率进行数据化分析和看板展示。

7
安全优先

数据安全、脱敏与合规是生命线。从原型设计第一天起就将安全机制放在核心位置。

8
避免过度工程

绝不微调能通过 Prompt 解决的问题，不预训练能通过 RAG+微调解决的场景。

💡 销售三原则：
① 永远用"人力替代成本"做锚点——先算客户现在花多少人力钱，再报 AI 方案价格；AI 成本 < 人力成本 1/3 时成交率最高。
② 永远给三档方案——低配（API 快速起步）、标配（推荐方案）、高配（私有化/微调）。80% 选标配。
③ 永远拆分一次性与持续性成本——主动给出 3 年 TCO 表格的销售，赢单率显著更高。
